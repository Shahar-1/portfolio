# Shahar Banu · Portfolio

Personal portfolio of **Shahar Banu**, a frontend-focused software engineer working with React, Next.js and TypeScript.

The page is designed to answer three questions quickly: who I am, what I build, and why it is worth reading further.

## Highlights

- **Clean, dark design** with one accent colour, generous whitespace and subtle motion only
- **Interactive terminal** in the hero: type `help`, `projects`, `skills`, `open contact` and more
- **Command menu:** press `Ctrl + K` (or `⌘ + K`) to jump around the page
- **Project filters** (Web, Mobile, AI, Full-stack)
- **Accessible by default:** semantic HTML, skip link, keyboard-friendly controls, visible focus states, ARIA labels on interactive parts, and `prefers-reduced-motion` support
- **Responsive** from small phones to wide desktops, with no horizontal scroll
- **SEO basics:** descriptive title and meta description, Open Graph tags, JSON-LD `Person` data and an inline favicon
- **No dependencies and no build step:** plain HTML, CSS and JavaScript

## Project structure

```
index.html   page content and metadata
style.css    design tokens, layout and components
script.js    scroll reveal, project filters, terminal and command menu
server.js    optional tiny Node.js static server for local use
```

## Run locally

Open `index.html` in a browser, or serve it with Node.js:

```bash
node server.js
# then visit http://localhost:3000  (set PORT to change it)
```

## Deploy

- **GitHub Pages:** repository *Settings → Pages → Deploy from a branch → `main` / root*
- **Vercel or Netlify:** import the repository; no build settings are needed
